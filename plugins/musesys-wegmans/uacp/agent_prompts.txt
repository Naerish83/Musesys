⚙️ STATUS WORKFLOW LOGIC
Automated Status Progression (forward-only):
Transition 1: Order Placed → Processing

Triggers when ANY of these fields are populated:

TRX Order # has value
Is Drop Ship? is checked
Purchase Order # has value


Status automatically updates to Processing

Transition 2: Processing → Partially Shipped OR Completed

Triggers when Tracking # is entered
Conditional logic:

Calculate total To Ship quantities across all line items
IF sum(To Ship) < sum(Qty) → Status = Partially Shipped
IF sum(To Ship) = sum(Qty) → Status = Completed
IF To Ship fields empty, assume full quantity → Status = Completed



Transition 3: Partially Shipped → Completed

Triggers when additional tracking added AND all remaining quantities shipped
Re-evaluate sum(To Ship) vs sum(Qty) with each update

Status Dropdown Behavior:

Display current status
Make read-only if auto-managed, OR
Allow manual override with validation (can only move forward through stages)
